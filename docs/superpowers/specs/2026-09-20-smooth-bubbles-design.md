# 气泡流畅度修复

用户反馈气泡不流畅。原实现使用 100ms 定时器更新位移和透明度，只有 10Hz；滚动时重复计算所有气泡位置，产生跳位。

改为 requestAnimationFrame 同步显示刷新，每帧仅更新透明度与 translate3d。淡入 1.4 秒、淡出 1.6 秒采用 smoothstep 缓动，仍包含在原有十秒寿命中。页面后台取消动画帧，回到前台重置时间基准。原队列、随机组数与暂停条件保持不变。

气泡记录出现时的页面滚动位置，随后根据滚动差值移动，保持相对页面的位置，不在滚动过程中重新排序。屏幕尺寸改变或成功祝福卡影响布局时，先将气泡层淡出，等待尺寸稳定后统一计算位置，再淡入，避免看到瞬间换位。

验证：原队列测试通过；真实浏览器手机和电脑连续采样 30 帧均观察到位移与透明度更新；检查滚动前后的文档位置、缩放后避让、气泡开关和控制台错误。物理手机的实际帧率仍取决于设备与浏览器。
