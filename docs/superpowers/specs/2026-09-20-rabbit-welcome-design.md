# 玉兔送月饼开场

## 最新调整：简化按钮与气泡排版

依用户要求移除开场的可见跳过按钮，约 5.4 秒后自动淡出；仍保留键盘 Escape 的原生退出能力与页脚重看入口。移除右上角暂停背景动画按钮，同时保持系统减少动态效果、后台暂停和打开编辑器时暂停的内部机制。

祝福气泡显示昵称与两行正文预览，正文采用宋体风格，手机 12px、电脑 14px。手机气泡宽度约 132–166px，扩大月亮上下空白，优先在左上、右下错落出现；整段标题、正文、留言表单与页脚作为避让区域。气泡降低边框强度并缩小漂移幅度，避免互相遮挡。每组仍按原队列轮换，空间不足时只显示能够安全容纳的数量。

以下为初始设计记录，按钮行为以本节为准。

用户请求玉兔端着月饼送祝福的开场动画。沿用深青月夜与暖金色，使用内联 SVG 插画、CSS 动画和浏览器原生 dialog，兼容独立离线 HTML，不依赖图片或第三方服务。

同一标签页的会话首次访问播放约 5.4 秒：玉兔端盘从下方轻轻跃入，站稳后点头，文字“月满人团圆 / 中秋喜乐安康”渐显，最后淡出至原主页。始终提供跳过按钮，Escape 可退出，结束恢复正文操作与焦点。页脚提供“重看玉兔送福”。不新增配乐。

开场遮罩占满视口、锁定底层滚动，屏蔽底层表单交互和留言气泡；后台标签页暂停计时和 CSS 动画。同一会话刷新不重复播放。系统减少动态效果时展示三秒静态祝福，可立即跳过。JavaScript 加载失败时 dialog 保持关闭，不阻挡主页。动画脚本位于现有贺卡模板快照之后，避免保存动态中间状态。
