中秋 · 月夜来信（孔明灯与云雾动态循环版）

在线网站：https://nuo-huang.github.io/mid-autumn-wishes/
推荐直接把这个链接发给朋友，手机浏览器即可打开。公共留言已接入 Supabase 云数据库，可跨设备读取。

1. 电脑：用浏览器打开 mid-autumn.html。
2. 手机：将 HTML 文件传到手机，下载后用支持本地 HTML 的浏览器打开。部分聊天软件或系统“文件”预览不执行网页脚本，需要选择“在浏览器中打开”。
3. 打开页面即有全屏孔明灯缓缓升空、轻轻摇摆，三层云雾横跨整个屏幕，以不同速度循环飘动。滚动页面时，动态背景依然覆盖屏幕。点击“开启月光祝福”，观看 3、2、1 粒子倒计时与爱心祝福，孔明灯与云雾持续循环。轻点月亮区域可散出星光。
4. 点击“写下我的祝福”，填写称呼、祝福与署名，再点击“保存这份祝福”，下载包含修改结果的新 HTML。将新文件发给对方即可。
5. 右上角按钮统一暂停或开启孔明灯、云雾、文字雨与粒子动态效果。切到其他页面时停止绘制，返回后继续。系统开启“减少动态效果”时，孔明灯与云雾静止，祝福直接呈现，不播放倒计时。

本文件不依赖网络、Python、图片或字体下载。无背景音乐。
部分 iPhone 本地文件预览、微信/QQ 内置预览不支持完整网页脚本。如果本地文件不能运行，可将 HTML 托管到静态网站后，用手机浏览器访问 HTTPS 链接。
在线网站已发布；以下本地 HTML 使用方式适用于下载后离线播放贺卡。
前端已拆分到 frontend/ 目录，修改后运行 node build.cjs 可重新生成单文件 HTML，不会更改数据库。Supabase 云端接入代码见 supabase/，配置和发布方法见“云端部署步骤.md”。
现已附带 server.cjs 和 SQLite 数据库服务：安装 Node.js 24 LTS 后，在本目录执行 node server.cjs，再访问 http://127.0.0.1:8787，可使用公共留言板。留言会在服务端持久保存，不同设备访问同一服务即可共享。部署方法见“部署说明.md”。
直接双击 HTML 仍是离线贺卡，不连接留言数据库。“写下我的祝福”修改的是贺卡文字；“留下祝福”才是发送公共留言。下载贺卡只保存贺卡文字，不会备份公共留言。需要共享留言时请访问上面的在线网站。

灵感参考：落落莓. 的抖音作品“Python中秋代码｜以代码绘明月，共庆中秋佳节”。保留汉字雨、粒子倒计时、爱心的创意元素，网页代码独立编写。
